# Changelog

## 1.1.0

- Added English, Hindi, and Telugu language options for the homepage and preset affirmations.
- Added separate affirmation files for English, Hindi, and Telugu.
- Added an optional AI reflection assistant below the preset affirmation.
- Added BYOT online assistant mode for users who want to provide their own AI API key at runtime.
- Added local Ollama assistant mode for users who want to connect to a local AI model.
- Added graceful fallback behavior when the AI assistant is unavailable.
- Updated documentation for local setup, AI integration, user guidance, security notes, and environment examples.

## 1.0.0

- Added Streamlit app.
- Added random affirmation display.
- Added affirmation text file.
- Added frontend image.
- Added Spec Kit documentation.
